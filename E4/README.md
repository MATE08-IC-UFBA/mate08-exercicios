# Avaliação de Software de Pesquisa

1. Escolher um software de pesquisa de um docente do IC-UFBA
2. Fazer um fork do projeto escolhido
3. Fazer um reconhecimento inicial e colocar em reconhecimento.md
4. Fazer avaliação de sustentabilidade e FAIRness e colocar em relatorio.md
5. Se achar pertinente, submeter uma contribuição ao projeto, por exemplo, um arquivo .cff.
